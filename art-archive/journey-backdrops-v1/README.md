# Journey backdrops — version 1

These are the original five soft-watercolour Journey Mode backdrops archived
before the landmark-focused New Zealand revision.

To restore one, copy its `.webp` file back into `public/assets/` and update
`src/game/assets.ts` if the backdrop identifier has changed.

- `cape-reinga.webp`
- `waitomo-caves.webp`
- `taupo.webp`
- `queenstown.webp`
- `christchurch.webp`
